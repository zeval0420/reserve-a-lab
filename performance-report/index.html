What changed

Scripts and stylesheets

  • All libraries are served from the site itself instead of 6 different CDNs (jQuery 3.3.1, Bootstrap 3.3.7, Bootstrap Icons 1.10.5, DataTables 1.13.6 + Responsive + Select, bootstrap-multiselect 0.9.13, Quagga2 1.12.1). Versions are unchanged.
  • Pages now load only the libraries they use ($pageAssets in helperFiles/headData.php): DataTables only on the tracker, approvals and inventory pages; multiselect only on the request form and approvals; the barcode scanner only on inventory, deferred.
  • Removed the second copy of the barcode scanner (two versions were loading on every page) and the JsBarcode library, which no page used.
  • The calendar library (123 KB) loads only when “View Calendar” is first clicked, instead of blocking every page.
  • Removed the bootstrap-multiselect stylesheet link, which had always returned 404.
  • Deleted two files nothing referenced: helperFiles/HeadFoot.css, helperFiles/tables.js.
  • Local CSS and JS files carry a ?v= version, so browsers can cache them for a year and still pick up edits.

Fonts

  • Raleway, Inter, Playfair Display and Plus Jakarta Sans are self-hosted as WOFF2 with font-display: swap (the same files Google Fonts served).
  • The fonts used for the first text on screen are preloaded.

Images

  • Every image under img/ was recompressed in place, keeping names and formats, so database paths and galleries still work: 137.4 MB → 17.2 MB.
  • WebP copies (and 640 px thumbnails) live in img/_opt/; the server sends the WebP automatically to browsers that support it, with no change to any URL.
  • New uploads are downsized to 1920 px and get WebP copies automatically (helperFiles/image_optimizer.php, hooked into every upload, replace, rename and delete path). tools/optimize_images.php rebuilds the copies from the command line.
  • Lab cards use <picture> with WebP sources; the first visible card photo loads at once with high priority (it is the largest element on the home pages), the rest load as you scroll.
  • About page: the hero image is preloaded; team and gallery photos load as you scroll and have width and height, so nothing jumps.
  • img/logo.png: 248 KB → 24 KB (320 × 320, transparency kept).

Layout shifts, LCP and interaction

  • Login page: the card and side panel no longer fade in from fully transparent (they still slide in). Lighthouse could not measure the page on mobile before (NO_FCP).
  • Request form: the two multi-select boxes get their final height before the plugin runs, so the form no longer jumps; the header background (the largest element) is preloaded.
  • Header and footer logos have width and height; the footer logo loads lazily.

Server (Apache)

  • Enabled mod_brotli, mod_deflate, mod_expires and mod_filter in C:\xampp\apache\conf\httpd.conf (backup: httpd.conf.bak-perf).
  • New .htaccess: Brotli or gzip compression for text files; cache headers (1 year for versioned files, fonts and vendor files, 30 days for images, 1 day for other CSS/JS, nothing added for PHP pages); WebP negotiation; web access to tools/ blocked. Every block is guarded with <IfModule>, so the file is safe on a server without those modules.
